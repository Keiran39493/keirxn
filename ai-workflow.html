Productivity Workflow Agent System (PWAS)

My workflow connects three tools: Google Drive stores my files, Claude reads and works with them, and Notion keeps the results organised.

How the pieces fit

  1. 1. CollectGoogle Drive

    Lecture slides, PDFs, papers and notes go into one Drive folder per course or project.

  2. 2. ThinkClaude

    Claude reads the files straight from Drive to summarise them, answer questions and draft notes or plans.

  3. 3. OrganiseNotion

    Claude writes the results into Notion pages and databases, so notes, tasks and deadlines live in one place.

Set it up yourself

You need a Claude account, a Google account and a Notion workspace. Which connectors you can use depends on your Claude plan.

Step 1: Connect Google Drive

  1. In Claude, open Settings and go to Connectors.
  2. Find Google Drive and select Connect.
  3. Sign in with your Google account and allow access.

Step 2: Connect Notion

  1. In Settings → Connectors, browse the connectors and choose Notion.
  2. Select Connect and sign in to Notion.
  3. Choose which pages Claude can access. Share only what it needs.

Step 3: Use both in a chat

  1. Start a new chat and open the tools menu below the message box.
  2. Make sure Google Drive and Notion are switched on.
  3. Ask Claude to use both, for example:
Read the lecture notes in my Drive folder "Networking – Week 3", summarise the key concepts, and create a page in my Notion "Study Notes" database with the summary and five revision questions.

Using Claude Code instead?

Add Notion as an MCP server from your terminal, then run /mcp inside Claude Code to sign in:

claude mcp add --transport http notion https://mcp.notion.com/mcp

Tips

  • Keep one Drive folder per course or project so Claude finds the right files quickly.
  • Set up a Notion database with properties like Course, Topic and Status first, so Claude fills in the same structure every time.
  • Check what Claude writes to Notion, especially when you are just getting started.
